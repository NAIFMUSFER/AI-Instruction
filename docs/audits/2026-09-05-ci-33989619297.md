## Root cause and reproduction

The large fixtures omit `levels[].index`. The shipped compiler already derives a rendering address from array position and records `LEVEL_INDEX_MISSING`, preserving the input model. Alignment diagnostics used raw `lv.index` instead. It built host keys such as `Fundefined|room`, collapsed all missing-index levels under `Fundefined`, and searched for a non-finite roof level.

At 20:30:36 UTC and 20:36:11 UTC the log reports, for each large fixture:

- Hosted objects checked: **1,378**; unresolved transforms: **1,378**.
- Roof transform unresolved; no finite actual elevation.
- One collapsed `Fundefined` level, with null expected/actual plate values.

The geometry was visible: pixel, camera, finite bounds, mode-toggle invariance and resize checks passed. The page boot summary was **22/22 PASS**, and visual summary **320/326**, with exactly the six failures above. This is not a browser-download failure or a black-frame failure in this run.

A new Node integration test runs the actual shipped compiler, actual Three.js boxes/world matrices and actual shipped diagnostic function. Before repair it produced **13 passed / 8 failed**: the six CI failures plus two checks exposing collapsed level counts. After repair it produced **21/21**; three added provenance checks bring the final test to **24/24**. Deliberately displaced furniture, upper-floor slabs and roof still fail their respective diagnostic checks.
